# でんしゃしょうぎ 🚄

未就学児（4〜6歳）向けの、電車テーマの将棋風ボードゲームです。

## あそびかた

1. `index.html` をブラウザで開きます（ダブルクリックでOK）
2. 「はじめる」をタップしてゲーム開始
3. 「あか」と「あお」が交互に電車を動かします
4. 相手の **しんかんせん**（☆）を取ったら勝ち！

## ルール

### でんしゃのしゅるい

| でんしゃ | うごきかた |
|---|---|
| ふつうでんしゃ ◯ | まえに 1マス |
| とっきゅうれっしゃ △ | まえ・うしろ・みぎ・ひだりに 1マス |
| かもつれっしゃ □ | ななめに 1マス |
| しんかんせん ☆ | ぜんほうこうに 1マス（とられたら まけ！） |

### あそびかたのポイント

- でんしゃをタップすると、いけるマスが **みどりのまる** で光ります
- 光っているマスをタップすると、でんしゃが移動します
- あいてのでんしゃがいるマスに移動すると、そのでんしゃを取れます
- 「もどす」ボタンで 1手もどせます（各プレイヤー 2回まで）

## 保護者の方へ

- **対象年齢**: 4〜6歳（保護者と一緒に遊ぶことを推奨）
- **プレイ人数**: 2人（同じ端末で交互に操作）
- **プレイ時間**: 1局 3〜5分
- **インストール不要**: ブラウザで `index.html` を開くだけで遊べます
- **オフライン対応**: インターネット接続不要
- **広告・課金なし**: 安心して遊ばせてください
- **個人情報の収集なし**: データの送信は一切行いません

## 動作環境

- iOS Safari 16以降
- Android Chrome 最新版
- PC Chrome / Edge / Safari 最新版

## 技術的な補足

- HTML / CSS / JavaScript のみで構成（フレームワーク・ライブラリ不使用）
- 効果音は Web Audio API で生成（外部音声ファイル不要）
- 電車のイラストはオリジナルSVG（実在の車両の色・形をモチーフにしたデフォルメ）
